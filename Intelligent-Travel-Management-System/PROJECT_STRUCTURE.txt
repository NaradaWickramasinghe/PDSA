KEY COMPONENTS OVERVIEW
=======================

1. CONTROLLERS
   - OptimizationController: Handles REST API endpoints for optimization requests

2. SERVICES
   - OptimizationService: Core service logic for running optimization algorithms
   - BenchmarkService: Handles benchmarking and performance testing

3. MODELS (Optimization Algorithms)
   - BranchAndBoundOptimizer: Exact algorithm for multi-objective optimization
   - ParetoFrontierOptimizer: Dynamic programming approach for Pareto frontiers
   - GeneticRouteOptimizer: Metaheuristic genetic algorithm
   - TravelGraph/TravelNode/TravelEdge: Graph data structures
   - RouteCandidate/OptimizationResult: Result management

4. DATABASE LAYER
   - Entity Models: Node.java, Edge.java
   - JPA Repositories: NodeRepository, EdgeRepository
   - Optimization Repositories: OptimizationNodeRepository, OptimizationEdgeRepository

5. DTOs (Data Transfer Objects)
   - OptimizationRequest: Input parameters
   - OptimizationResponse: Algorithm output
   - BenchmarkResponse: Performance metrics
   - NetworkResponseDTO: Network data
   - RouteSummaryDTO: Route details
   - AlgorithmType: Enum for algorithm selection

6. FRONTEND
   - index.html: Single-page application with interactive map visualization
   - Features: Route planning, algorithm comparison, benchmarking

7. CONFIGURATION
   - pom.xml: Maven dependencies (Spring Boot, JPA, PostgreSQL)
   - application.properties: Database connection and app settings


BUILD & DEPLOYMENT
==================

- Framework: Spring Boot 4.1.0
- Language: Java 17
- Database: PostgreSQL (Supabase)
- Build Tool: Maven

Default Profile: "default"
